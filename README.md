# Myl2D - paquetes de imagenes

## Descargar el juego

**[Reliquias de Primer Bloque v1.3.0 - portable para Windows (279 MB)](https://github.com/mechjook/Myl2D-imagenes/releases/download/v1.3.0/Myl2D_v1.3.0_portable.zip)**:
descomprimelo y abre `Myl2D.exe`. Las versiones siguientes llegan como
actualizaciones desde el propio juego.

## Paquetes de imagenes

Paquetes de imagenes del juego **Reliquias de Primer Bloque (Myl2D)** en tres
calidades. El juego los descarga solo, desde el recuadro "Calidad de las
imagenes" (primer arranque o Ajustes > Pantalla). No hace falta bajarlos a mano.

Cada release trae:

| Fichero | Que es |
|---|---|
| `manifest.json` | Lo que lee el juego: url, tamano y sha256 de cada paquete |
| `imagenes_completa.zip` | Las imagenes originales |
| `imagenes_media.zip` | Cartas al 70 % |
| `imagenes_baja.zip` | Cartas al 50 % (la que trae el portable) |

Las ilustraciones de las cartas son propiedad de sus autores y de Salo S.A.
